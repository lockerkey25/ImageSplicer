# Cool Image Effects :)

An image effects tool for people who want some Photoshop effects without opening Photoshop.

### Collage
Upload two images. 
Lenticular Image Effect.

## Effects

**Glass Slices**

**Chromatic Aberration**: Splits the R, G, and B channels and offsets them.

**Path Blur** Draw a freehand path on the canvas. Pixels near the path get motion-blurred along the path's tangent direction. Blur length and falloff radius are adjustable. Ctrl/Cmd+Z undoes the last stroke.

**Noise and Grain**
- Film: gaussian-distributed grain, like analog film
- RGB
- Scanline: horizontal CRT lines with adjustable spacing and width
- Dust

Each type supports **Mono** (luminance noise) or **Color** (independent channel noise) modes.

**Gradient Map** Click any color stop swatch to change its color, add or remove stops, and dial in opacity and blend mode (Normal, Multiply, Screen, Overlay, Color).

**Halftone**
- *Dots*
- *Lines*

**ASCII**
